This is my first blog post on this website so I want to cover what the website's purpose is, alongside immediate plans for the website. At first I'll loosely be working on different parts of the website as I try to get it to a stable state but then a more streamlined approach will be taken.

## Purpose

I created this website as partly as a portfolio and partly for a nice side project. I am the kind of person who likes to work on something even if it serves no real purpose to anyone outside of myself. One thing I've always struggled with is web development so what better way to improve those skills than by creating a website.

My main interest when it comes to programming is game development so I am also challenging myself to make a game that will be hosted on this website which will be hosted [here](/game/?u=1). It will be purely in Javascript and will be using HTML5's canvas element so I will be writing my own game library to facilitate it's creation. I am still deciding on what that game will be but I'll be revealing it in a blog when I have a better idea of what it will be.

I also plan to use this website as a portfolio of sorts, showcasing projects I have worked on and any future projects. I want it to be a nice confined space to show off my skills to any prospective teams I might join.

## First Steps

I already have the rough design of this website in place but there are bound to be issues cropping up here and there in these early stages. I went with a design reminiscent of Final Fantasy VII's UI as I am a big fan of Final Fantasy and to be quite honest it is a quick way to have the website up and running as quickly as possible.

## Future Prospects

One thing I know will have to be done is a redesign of the website, while it feels nostalgic now of what the internet was decades ago, if I am to learn to create websites properly I should learn some more modern design principles and use the full extent of the browser's capabilities. This won't be for a while yet but will be something I do on the side.

Some time in the coming days I want to write about potential future projects including revisiting an old game jam entry I worked on called [Hold the Line](https://actualcannibalpanda.itch.io/hold-the-line). I probably won't be making it a fully fledged game to be released for big bucks but since I did not have the time to complete the game at the time I'd really like to at make it fully playable.
